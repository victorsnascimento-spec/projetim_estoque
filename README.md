## 🛠️ Funções do Sistema

*   **`travarMenu()`**: Pausa a tela com a mensagem `"Pressione <ENTER> para continuar..."` para que o usuário consiga ler as informações antes de voltar ao menu.
*   **`adicao()`**: Abre o assistente para cadastrar novos itens. Pergunta a quantidade de produtos que serão inseridos e coleta Nome, Quantidade, ID e Local de cada um.
*   **`arrumandoID()`**: Varre todo o estoque e reescreve os IDs em ordem sequencial (0, 1, 2, 3...), corrigindo falhas na numeração após exclusões.
*   **Menu Principal (`while True`)**: Controla as escolhas do usuário de 1 a 7, direcionando para relatórios, buscas por ID, alteração de quantidades, exclusão de itens ou saída do programa.
